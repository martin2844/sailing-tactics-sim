# Production cutover to the independent2026 driver

2026-10-07. `engine.worker.ts` advances EngineRuntime directly. It no longer
creates front/back OffscreenCanvas DCs, loads bitmap fonts, invokes the original
paint lifecycle or world compositor, copies a raster surface, or reads pixels.
Minimum pace delays are enforced by the host scheduler. Initial conditions are
primed before publication; transport generations/sequences own restart and
next-race model acceptance. Results scoring is an engine transition.

The graphics worker retains faithful hull, crew, rig, luffing, boom and penalty
colors through private geometry extraction. Its projection width is a fixed
studio profile independent of scene pixels and camera. Ordinary snapshots carry
empty legacy2D boat packets; Three.js renders the actual meshes. Course/key
screens use owned DOM/SVG rather than original bitmaps. Guide target selection
uses the typed read-only selector, preserving engine classification.

The remaining compatibility adapters are explicit: recovered numerical JS and
address-space/Float80 support, private boat face extraction, source-derived guide
rays and private coach/weather/chart extraction. These are not an offscreen game
loop. A later pure presentation rewrite must preserve their geometry/content.
This cutover does not mark every2026 MVP or advanced original mode complete.
