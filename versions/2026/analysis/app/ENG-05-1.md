# ENG-05-1 — Own host calibration and remove the old lifecycle wrapper

2026-10-07. The worker no longer invokes original `paintLifecycle`,
`drawPaintContent` or `drawSimulationFrame`. Canonical host calibration,
transition dispatch and step ordering are explicit 2026 functions. The obsolete
screen-dispatch preparation shim is removed; that preserved module is copied
byte for byte again.

The compatibility back surface still supplies world drawing/pixel semantics,
and its image is retained for the remaining original information panels. Thus
this milestone removes lifecycle orchestration, not all offscreen rendering.
The unresolved drawing/randomness question must be resolved before the latter
can be eliminated without silently changing behavior.

The typed calibration port matches original dimensions/caps/scales and exact
F64 spills in eighteen host profiles, including width and height caps and an
unsigned application handle. Build/type checks pass.

[69 paired 2026 boundaries and ten frozen 2010 boundaries](cutover-host-2026-10-07/verification.json)
match full state, RNG/time/frame and retained shore context. The evaluation server
replaces all three forbidden original lifecycle entry points with throwing
bodies **for the candidate only**; successful startup, racing, panels and arming
slowdown prove those entries are not invoked in these paths. No original files
or production module bytes are altered by that guard.

[Phase ledgers](cutover-host-2026-10-07/phase-ledgers.json.gz) remain untruncated.
The actual compatibility surface and pixel dependencies remain open acceptance
items. No complete independence is claimed.
