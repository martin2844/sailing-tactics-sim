# Retained initialization, dynamics and integration

All **13,389** captured original-code calls pass strict native JavaScript replay. They comprise139 actual original race initializations,7,550 retained position integrations and5,700 retained complete boat-dynamics calls. Every mutable byte, full SHA256, RNG state and ordered sound request matches. All36 semantic CString cells are observed on every initialization/integration response, and boat names remain unchanged across the retained source calls. The original executable file and loaded text are unchanged; the observed control word is `0x027f` throughout.

The first12 profiles each initialize the race at `0x41be70` and then call the real original `0x43cf60`100 times without resetting state or reseeding the RNG. Seven additional13-profile groups cover the remaining91 profiles from the original initialization manifest, each with50 retained integrations. Together these cover all27 boat selectors and20 basic/named/custom venues. A further24 profiles cover the legitimate menu courses5/6/11/12/13/14, start modes1/2/5 and enabled/disabled current settings. Twelve separate profiles execute the complete original `0x43a030` for every initialized boat before each of50 integrations.

The fixture groups avoid one JSON file exceeding Node's string-size limit. The test dispatcher is `tests/retained-integration.test.js`; `TACT_RETAINED_FIXTURE` can select one group when investigating a discrepancy. `tools/prepare-retained-integration-inputs.js` creates the representative manifest, `--remaining` creates the seven additional groups, `--physics` creates the dynamics/integration closure, and `--modes` creates the extra course/current/start profiles.

Initial input data comes from the existing source-derived option preparation. Before the original initializer executes, the motion level, speed divisor and saved divisor are supplied as original I32 values from the complete `0x464940` mapping. This corrects the older isolated initializer manifest's F64 preparation at the I32 divisor address; that field did not affect the isolated initializer itself, but a zero divisor would be invalid for integration.

Continuation rows preserve the exact initialized state, semantic names and native CRT RNG. Half the simple chains and all physics chains explicitly supply the original paint counter1..60 to exercise current/dynamics cadence. The other simple chains have no intervening state patches. These are recorded numerical closure proofs; they do not claim a full application/paint lifecycle or identical Canvas rasterization.

`analysis/retained-integration-native-comparison.json` records every fixture hash, native source-integrity evidence, tested source hashes and exact group/call counts. No captured resulting-state lookup, tolerance comparison or original text modification is used.
