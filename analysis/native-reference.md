# Original 2002 native reference

The independent authority index records **98,775 verified cases across 209 complete original routine addresses**: 98,472 isolated calls, 300 retained simulation frames and three connected initialization lifetimes. Every expected native result matches exactly. Repeated group reports are subsets and are excluded from the total. [native-reference-index.json](native-reference-index.json) lists the seven independent datasets; `tools/update_native_reference_index.py` validates and regenerates it from their completed reports.

The three retained chains provide a stronger connected comparison than independent prepared inputs. Each begins with preserved original data and explicit settings, runs original integer/random initialization, boat options, the original viewport-calibration fragment and race initialization, then retains actual native globals, RNG and original CRT/CString lifetime for 100 complete `00404020` frames. JavaScript separately initializes from original data and matches every frame without receiving native after-state as input. A second native run confirms all three initialization lifetimes and all 300 frames. Actual normalized course/class/weather values are `1/6/0`, `8/7/0` and `6/6/5`, including two human players and original snapshot restore. See [native-frame-chains-p53-reference-comparison.json](native-frame-chains-p53-reference-comparison.json). Calibration `00403c62..00403cb9` executes unchanged and stops at a hardware breakpoint before CreateBitmap; it is a reviewed fragment, not a separate recovered function or proof of the whole MFC paint lifecycle.

The intact original CRT, first paint, full frame and scene entries use control word `0x027f`, selecting 53-bit arithmetic. A separate debugger observed this through normal Wine startup using hardware breakpoints without instruction, game-data or control-word writes. [startup-precision.json](startup-precision.json) retains observations and tool hashes. Production reference assets in `assets/data/pc53/` use this context. Earlier `0x037f` assets and isolated comparisons remain explicit 64-bit arithmetic references. The 936 separately captured startup-context screen calls and 180 independently prepared complete frame calls also agree exactly; those 180 prepared cases alone are not continuation evidence.

Full-state comparisons cover all 118,784 bytes in `00491000..004adfff`, including unchanged gaps, through SHA256 and exact before/after deltas. RNG, integer and floating results, ordered sound requests, ordered GDI requests, HUD text and declared timer observations are strict. Selected scalar routines additionally compare all ten ST0 extended bytes. Synthetic geometry and explicit GetPixel returns are declared inputs. Hardware FSIN/FCOS/FPATAN differs from Unicorn at some low bits; measured corrections preserve emulator baselines and immutable before-correction reports. No numeric tolerance or executable edits are used.

The runner requires SHA256 `881dc85dc7500a5ad09e09091d4dd53f8c091f5630d5fabdcc887cc4b007acea`. Its own PE starts at `00300000` and reserves a dedicated data section at `00400000`. It verifies ownership, copies the fixed original image unchanged, zero-initializes BSS and applies original section protections. The preserved original lacks relocations; ordinary LoadLibrary mapped it at an unusable base, while direct allocation collided with a foreign Wine mapping. Those mappings were never replaced or unmapped. Complete original `.text` is checked before calls and at completion; the source file is checked again afterward.

Original IAT data receives 358 normal imported functions; bounded sound/GDI/cursor/timer observations use explicit owned API bindings. Original CRT TLS uses TlsAlloc/TlsSetValue and the original unchanged accessor. Commands accept only fixed reviewed dispatch IDs and fixed data scope, never arbitrary executable addresses. The 131,072-command bound covers the complete aggregate suite. Independent calls establish their declared `027f` or `037f` context; retained chains initialize `027f` once and verify it remains unchanged across calls.

Only runtime TLS identity, declared original CRT allocator bookkeeping and the semantic HUD allocation pointer are comparison-normalized. Original CRT locks/heap/CString/formatter instructions execute unchanged. Exact raw allocator bytes remain in SHA256-linked `*-runtime-evidence.json.gz` artifacts; compact report JSON retains the results and normalization scope. `tools/compact_native_reports.py` changes evidence storage only. Text bytes, game state and ordered commands remain exact. Sound observations return BOOL1 and compare resource/module/flags; pixel observations preserve explicit synthetic return sequences. Neither proves actual raster or audio identity.

Live normal island initialization revealed actual retained local stack values rather than a universal zero. Read-only hardware observations confirmed the first predecessor X/Y at their consuming instructions after the original reset, Round-the-Island menu, Start and Space path. Normal reinitializations produced different retained values.
